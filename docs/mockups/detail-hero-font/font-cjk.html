现状（未换） — — 0 汉字走的是**系统衬线**：Windows 上是宋体（SimSun），macOS/iOS 上是宋体-简（Songti SC），Android 上多半没有衬线 → 掉到黑体。三端不一致，且宋体在 43px 下笔画偏细、边缘发虚

三个必须知道的事实（都已在本页实测）：
1. 单换汉字不够：候选 webfont 都不含完整韩文 —— 思源宋体 SC 与霞鹜文楷的 unicode-range 里只有 U+AC00–AC01 等零星码位， 没有整块谚文（U+AC00–D7A3）→「(배주현)(희진)」这类韩文会回退到系统字体（本机实测是 Malgun Gothic，一款黑体， 和汉字的明朝骨架明显不搭）。所以推荐把 候选 1B（思源宋体 + Noto Serif KR） 作为正解；只上候选 1 的话，韩文仍是老样子。
2. Playfair 的位置不能动：它必须排在第一位，否则拉丁字母会被汉字字族的拉丁字形接管（思源宋体的拉丁是另一种味道，会抢掉刊头气质）。
3. 分档类名照旧生效：本页每格都带真实的 hero-cover-name--xl/long，换字体不影响 nameSizeTier() 的分档结果。
